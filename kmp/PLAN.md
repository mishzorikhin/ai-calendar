# Инструкция: перенос интерфейса в KMP

Это рабочий план, не описание для пользователя. Цель — чтобы клиент в `kmp/` выглядел как веб на
https://aicall.mish-tech.ru/ и как экраны в `src/screens`. Не изобретать второй интерфейс.

Код веба и живой сайт уже есть. Мешает не отсутствие исходников, а привычка рисовать «примерно то же»
по памяти. Так делать нельзя.

## Как смотреть, прежде чем писать экран

Один экран — один проход. Не начинать следующий, пока текущий не совпал.

1. Открыть живой экран на https://aicall.mish-tech.ru/ в ширине телефона (390×844), тёмная и светлая тема.
   Без сессии виден только вход (`src/screens/auth`). Остальное — после входа, плюс скриншоты в `.ux-audit/`.
2. Открыть tsx экрана и его `*.module.css` рядом. Читать размеры, а не пересказ: `font-size`, `padding`,
   `border-radius`, градиент, что лежит в нижней панели.
3. Найти, откуда данные: хук в `src/api/queries.ts` и метод в `src/api/api.ts`. В KMP тот же путь уже есть
   или его надо добавить в `CalendarApi`, не выдумывать локальное состояние вместо сервера.
4. Перевести разметку в Compose в том же порядке узлов. Класс CSS — отступ и форма в `Modifier`, не новый дизайн.
5. Поставить сборку на телефон (`./gradlew :androidApp:assembleDebug`, `adb install -r`) и положить скрин
   рядом с кадром сайта. Отличие, которое видно сразу, — ошибка этого прохода, её чинить до следующего экрана.

Маршруты веба — `src/app/navigation.tsx`: `home`, `month`, `day`, `chat`. Отдельных вкладок «Сегодня / Месяц /
Задачи / Чат» нет. Задачи живут на главной. Месяц открывается с чипа даты, день — с «Открыть день», чат — с «∞».

## Что переводится как есть, что нет

Переводится:

- Дерево экрана, тексты, порядок, радиусы, цвета из `src/styles/global.css` (токены `--bg`, `--surface`, `--ink`,
  `--bar-gradient`, слои `--morning-*` / `--afternoon-*` / `--night-*`).
- Данные: события, задачи, месяц, чат, подтверждения. Контракт уже в `kmp/shared` (`CalendarApi`).

Не копируется буквально:

- React, CSS Modules, framer-motion, `BarSlot`. В Compose это `Column`/`Box`, `Modifier`, состояние экрана.
- Иконки из `src/components/Icons` — SVG. Их надо перерисовать `ImageVector` или взять те же path, а не подменять
  буквами «∞», «✕», «⌕».
- Голос (`src/lib/speech.ts`) на вебе — Web Speech. На Android/iOS это отдельный шаг, кнопка «Нажмите и говорите»
  пока может открывать чат, но место в панели должно быть то же.
- OAuth календарей и Web Push завязаны на браузер. Шторки можно нарисовать, сами подключения — позже.

Нижняя панель одна на всё приложение (`src/components/BottomBar.tsx`): слева «∞ Ассистент», справа «+ Событие»,
центр отдаёт экран. На главной и в месяце центр — «Нажмите и говорите». На дне — переключатель «Шкала / Список».
В чате центр занимает поле ввода. Фон устройства — `--bar-gradient`, лист контента кончается на высоте панели.

## Порядок экранов

Каждый пункт закрывается только после сравнения с сайтом. Файл KMP указан там, куда класть код. Общие куски
(круглая кнопка, чип, карточка, панель) — в `ui/Widgets.kt`, не копировать в каждый экран.

### 1. Вход — уже близко, сверить ещё раз

- Веб: `src/screens/auth/AuthScreen.tsx`, `Auth.module.css`.
- KMP: `ui/AuthScreen.kt`.
- Карточка по центру: «◐», «Календарь», подпись, сегмент «Вход / Регистрация», поля без обводки Material, белая кнопка «Войти».
- Адрес сервера на сайте не спрашивают: приложение ходит на `https://aicall.mish-tech.ru`. Поле адреса не ставить на карточку.

### 2. Главная

- Веб: `src/screens/home/Home.tsx`, `Home.module.css`, `NextEvent.tsx`.
- KMP: `ui/HomeScreen.kt`.
- Шапка: «Четверг, 22 октября» и «Открыть день ›»; справа поиск, аватар (цвет из `src/lib/avatar.ts`), чип `22 / окт` со значком календаря.
- Карточка `border-radius: 32px`: «Сегодня» ~48px, подпись «N событий в календаре», пилюля «Неделя».
- Если есть ближайшее событие: «Далее · 15:00–16:30», название ~32px, подзаголовок, кнопки «Изменить» и «Весь день».
- Если нет: «Свободный день» и «Нажмите, чтобы что-нибудь запланировать» — это текст на карточке, не отдельная плашка.
- Строка «Задачи и цели» и круглая «+». Пусто: «Задач пока нет» тем же крупным заголовком. Не пусто: `TasksGrid.tsx`, `HabitCards.tsx`, `PrepCard.tsx`.
- Поиск, неделя, аккаунт — шторки из `HomeSheets.tsx`, не новые экраны. Их очередь — пункт 6.

### 3. День

- Веб: `Day.tsx`, `Day.module.css`, `PartCard.tsx`, `EventCard.tsx`, `AllDayStrip.tsx`, `WeekStrip.tsx`, `Agenda.tsx`, `ModeToggle.tsx`.
- KMP: `ui/DayScreen.kt`. Панель в этот момент показывает `DayModeSwitch`, не текст «Нажмите и говорите».
- Шапка: день недели ~44px и дата серым (`--ink-soft`), справа круглая «✕» закрывает день и возвращает назад.
- Слои суток наезжают друг на друга (`margin-top: -26px`), скругление 30px. Утро — зелёный градиент и шкала часов, день — голубой, вечер — серый. Свёрнутый слой — заголовок и «2 события». Раскрыт один слой.
- Карточка события — белая, со значком типа, не полоска слева и не чипы Material.
- Под слоями — лента недели `WeekStrip`: Пн…Вс, выбранный день кругом, выходные красные.
- «Список» — `Agenda.tsx`, не второй самодельный список.

### 4. Месяц

- Веб: `Month.tsx`, `Month.module.css`, `MonthGrid.tsx`, `MonthPicker.tsx`, `TodayCard.tsx`.
- KMP: `ui/MonthScreen.kt`.
- «2026» и «Октябрь» тем же крупным кеглем, что день. Стрелки месяца — круглые кнопки, не символы в тексте.
- Сетка внутри белой карточки. Сегодня — чёрный круг. Точки — цвета `src/lib/badges.ts`, не больше двух и число.
- Под сеткой карточка выбранного дня: число, подпись, название ближайшего события. Стрелка на карточке открывает день.
- Тап по числу на сайте тоже открывает день с короткой задержкой. Повторить это, а не оставлять человека только в сетке.

### 5. Чат

- Веб: `Chat.tsx`, `Chat.module.css`, `ChatComposer.tsx`, `ConfirmCard.tsx`, `MemoryNote.tsx`, `DayPreview.tsx`.
- KMP: `ui/ChatScreen.kt`.
- Чат не отдельный «экран с заголовком Ассистент». Лента поверх светлого фона, реплика человека — тёмная плашка справа, ответ — светлая слева.
- Подсказки-чипы («Запланировать завтрак») из `src/mocks/assistant.ts`.
- Низ: круглая «‹» назад, белое поле, чёрный круг отправки. Это центр нижней панели, а не вторая панель над ней.
- Карточка подтверждения и пометка «Запомнил» — как `ConfirmCard.tsx` и `MemoryNote.tsx`. Поток SSE уже разбирается в `api/Sse.kt`.

### 6. Шторки, без которых главная неполная

Открывать через общий нижний лист (жест вниз, как `src/components/BottomSheet`), не через `AlertDialog` и не через новый экран.

- Событие: композитор, кнопка «+» и «Изменить». Поля и время — `src/components/EventComposer`.
- Задача: `TaskSheet.tsx`, кнопка «+» у «Задачи и цели».
- Поиск: `search/SearchSheet.tsx`.
- Неделя: `week/WeekSheet.tsx`, пилюля «Неделя».
- Аккаунт: `AccountSheet.tsx`. Аватар открывает его, а не сразу «Выйти».

Календари, напоминания, профиль и память — после этих пяти. Иначе главная так и останется без своих действий.

## Чего не делать в том же проходе

- Не рисовать вкладки «Сегодня / Месяц / Задачи / Чат».
- Не подменять иконки буквами и не оставлять стандартные `OutlinedTextField` / `FilterChip` там, где на сайте своё поле и пилюля.
- Не считать экран готовым, если совпали только слова. Сверять кегль заголовка, карточку, панель и пустое состояние.
- Не тащить в этот проход офлайн-очередь, push и OAuth. Их нет в вёрстке экрана, они не оправдывают чужой вид.

## Проверка

Из `kmp/`:

```bash
./gradlew :androidApp:assembleDebug
adb install -r androidApp/build/outputs/apk/debug/androidApp-debug.apk
```

На телефоне пройти вход → главная → день → месяц → чат и открыть шторку события. Рядом держать тот же сценарий на
https://aicall.mish-tech.ru/. Расхождение списками, не общим «похоже».
