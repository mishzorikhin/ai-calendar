# Клиент на Kotlin Multiplatform

Правила и подводные камни для агентов и разработчиков — в [AGENTS.md](AGENTS.md); статус переноса экранов — в [PLAN.md](PLAN.md).

Те же экраны на Android, iOS и в браузере. Общий код — Compose Multiplatform в `shared/`: вход, сегодня, месяц, день, неделя, задачи и чат с ассистентом, шторки события (просмотр, правка, ответ на приглашение), задачи, поиска, аккаунта (имя, пароль, уведомления, устройства), «Календари» (Google и Outlook через браузер, CalDAV, `.ics`, своя лента), «Ассистент обо мне», «Что ассистент знает», «Люди», карточки предложений; события с повтором, напоминанием, гостями и ссылкой, задачи со сроком и участниками. Данные приходят из Go-сервера этого репозитория, веб-PWA на React остаётся как был.

Собрано на Kotlin 2.4 и Compose Multiplatform 1.11. Веб — Wasm (и запасная сборка JS). Нужен браузер с WasmGC: актуальные Chrome, Firefox или Safari.

Это не замена PWA. Здесь нет голосового ввода, приёма push-уведомлений (сервер шлёт только Web Push, доставка на устройство — в веб-PWA; в приложении есть шторка «Напоминания»: когда напоминать, тихие часы, свои напоминания, список устройств, проверка), анкеты знакомства, картинок в чате и многодневных событий. Офлайн-очередь есть для событий и задач (повтор при открытом приложении, без Background Sync).

## Что нужно

- JDK 17 или новее (проверено на 21)
- Android: Android SDK, `local.properties` с `sdk.dir`
- iOS: macOS и Xcode. Собираются устройство и симулятор Apple Silicon (`iosArm64`, `iosSimulatorArm64`). На Linux эти цели только лежат в проекте. В Compose 1.11 нет `iosX64`, симулятор на Intel Mac этой сборкой не покрыт.
- Для веба сервер должен разрешить источник страницы: `CORS_ORIGINS=http://localhost:8088`

## Запуск

Из каталога `kmp/`:

```bash
# тесты общей логики (календарь, привычки, подбор времени, разбор потока чата, напоминания, адреса)
./gradlew :shared:jvmTest

# веб, http://localhost:8088 — порт 8080 занят Go-сервером
./gradlew :webApp:wasmJsBrowserDevelopmentRun

# статика для выкладки: webApp/build/dist/wasmJs/productionExecutable
./gradlew :webApp:wasmJsBrowserDistribution

# запасной веб на JS, если Wasm в браузере недоступен
./gradlew :webApp:jsBrowserDistribution

# Android, apk в androidApp/build/outputs/apk/debug/
./gradlew :androidApp:assembleDebug
```

iOS: открыть `iosApp/iosApp.xcodeproj` на Mac и запустить схему `iosApp`. Скрипт сборки вызывает `./gradlew :shared:embedAndSignAppleFrameworkForXcode`. В `iosApp/Configuration/Config.xcconfig` можно задать `TEAM_ID`.

На экране входа укажите адрес API. Пока адрес не задан, используется адрес из `defaultApiUrl()` (`Platform.kt`); он меняется на экране входа по ссылке «Сервер».

- Эмулятор Android видит компьютер как `http://10.0.2.2:8080`
- Телефон в той же сети — `http://IP-компьютера:8080` (или порт из `APP_PORT`)
- Веб с dev-сервера ходит на Go напрямую, поэтому нужен `CORS_ORIGINS`

Приложение само сообщает серверу часовой пояс устройства. HTTP без TLS приложение принимает только для localhost и частных адресов (`10.*`, `172.16–31.*`, `192.168.*`, `*.local`), остальное — только `https://`. На Android HTTP разрешён только в отладочной сборке (`androidApp/src/debug`); релиз ходит по HTTPS.

Сессия (токен и адрес) хранится на устройстве: SharedPreferences, UserDefaults или `localStorage`. В лог токен не пишется.

## Мелочи интерфейса

- Удаление события и задачи — с отменой: запись сразу пропадает, а на сервере удаляется через пять секунд, если не нажать «Вернуть».
- Ошибка запроса сама исчезает и даёт «Повторить»; пока идёт запрос, вверху тонкая полоса; на главной работает потягивание вниз, а при возврате в приложение экран обновляется.
- Формы: «Далее» на клавиатуре переводит к следующему полю (клавиатура сама открывается только в поиске), время события подбирается по ближайшему свободному окну, видно пересечение с другими событиями, день и срок выбираются календарём. Если в форме есть ввод, закрытие жестом спрашивает «Отбросить введённое?».
- На главной «Назад» сначала предупреждает, второе нажатие в течение двух секунд выходит. Экран дня листается свайпом в сторону.

## Анимации и значки

Пружины (`uiSpring`, `softSpring`, `bouncySpring`) переведены из `src/lib/motion.ts` (`Motion.kt`). Нажатие со сжатием — `Modifier.pressable`, каскадное появление — `Modifier.appear`, переходы экранов и шторки повторяют `screenVariants` и `BottomSheet`. Значки взяты из `src/components/Icons.tsx`. Выбор в переключателях (Шкала/Список, тема, день в ленте недели) «переезжает» плашкой (`SlidingKnob`, как `layoutId` на сайте). Вибрация отклика (`Haptics.kt`) — на отметках задач, выборе, листании, подтверждении и отказе и при закрытии шторки жестом; работает на Android и iOS, в вебе и JVM молчит. Шрифт — Inter 400/500/600/700 (TTF с кириллицей, лицензия OFL — `FONTS-LICENSE.txt`) из `shared/src/commonMain/composeResources/font`; класс `Res` генерируется при сборке (пакет `app.calendar.resources`).
