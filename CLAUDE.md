## Дополнительно для Claude Code

- Перед изменениями Go прочитайте `server/AGENTS.md`. Проверки выбирайте по области изменения
  из Definition of Done в корневом `AGENTS.md`.
- Скрипт `scripts/agent-setup.sh` предназначен для хука SessionStart: при `CLAUDE_CODE_REMOTE=true`
  ставит npm-зависимости, если нужно, и загружает Go-модули при наличии Go. Локально ничего не делает.
  Он не запускает проверки и не устанавливает Node, Go или браузер. Настройку хука и разрешения
  сверяйте с доступной в вашей среде `.claude/settings.json`; не предполагайте успешный запуск.
- Для UI используйте доступный браузер/Playwright: 390×844 и 375×667 для изменений вёрстки.
  Путь к Chromium определяйте в текущей среде, без жёсткой привязки к `/opt/pw-browsers/chromium`.
  Скриншоты и временные файлы сохраняйте вне репозитория, если задача не требует артефактов в git.
- Читайте раздел «Текущие ограничения» в `AGENTS.md`: очередь не изолирована между бэкендами, кэш `api`
  общий и лишь стирается при смене пользователя, подтверждение AI-удаления живёт в памяти процесса.
  Не выдавайте эти ограничения за исправленные.
- Для изменений только документации проверьте форматирование, пути и команды; сборка и тесты приложения
  не обязательны. В отчёте укажите выполненные проверки, пропуски и причины.
- Push выполняйте в согласованную ветку без force. Деплой на сервер требует отдельной явной просьбы;
  подробности окружения и секреты не дублируйте в агентских инструкциях.
