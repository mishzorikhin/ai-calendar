# REVIEW.md — чек-лист ревью

Для людей и агентов, которые ревьюят изменения в этом репозитории. Блокирующее — то, что ломает
пользователя, данные или правила из `AGENTS.md`; остальное — пожелания.

## Блокирует мерж

- **Корректность:** гонки таймеров (таймер без очистки, `setTimeout` в обработчике без `useTimeout`),
  устаревшие замыкания, неверные даты (смешение `Date` со временем и начала суток, часовые пояса,
  месяц с 0 vs с 1 в `/api/month`).
- **Контракт API рассинхронизирован:** поле изменено в Go-модели, но не в `src/domain/types.ts` /
  `api/http.ts`, или наоборот; новый метод есть в `http.ts`, но нет в `local.ts`.
- **Сервер:** нет валидации входа, ошибка отдаёт внутренние детали, запись в хранилище без
  блокировки, хендлер без теста.
- **Данные мимо слоя `api/`:** `fetch` в компоненте, импорт `mocks/calendar` в экран, ручное
  управление кэшем вместо инвалидации по `keys`.
- **`eslint-disable`, `!important`, `as any`, непроверенная индексация через `!`.**
- **Доступность:** иконочная кнопка без `aria-label`, модалка не через `BottomSheet`, скрытый
  интерактивный элемент без `inert`, зона нажатия < 40 px, текст с контрастом ниже нормы.
- **PWA:** изменены кэш-заголовки SPA или конфигурация Workbox без проверки обновления и офлайна.
- **Нет проверки:** `npm run check` / `go test` не зелёные, UI-изменение без визуальной проверки
  на 390×844.

## Обратить внимание

- Дизайн: токены вместо литералов цвета, единые радиусы и отступы, поведение на 375×667.
- Анимации: `useReducedMotion` для бесконечных, без массового `blur`, корректный `ref` у детей
  `AnimatePresence mode="popLayout"`.
- Размер компонентов: файл > ~150 строк с несколькими частями — повод разбить.
- Тексты интерфейса: русский, короткие фразы, «ёлочки», «ё», без канцелярита.
- README и `AGENTS.md` обновлены, если поменялись команды, структура или API.
